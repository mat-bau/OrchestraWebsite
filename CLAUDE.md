This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
# Start the server (regenerates gallery JSON + launches Flask on :5050)
python3 start.py

# Compile SCSS → frontend/style.css
npm run build

# Watch SCSS during development
npm run watch

# Deploy to production (GitLab CI)
git push gitlab main
```

## Tech Stack

- **Frontend**: Static HTML + ES modules (`<script type="module">`). jQuery 1.11.1 + FlexSlider + OwlCarousel loaded as classic scripts for legacy plugins.
- **CSS**: Sass CLI — sources in `frontend/src/scss/`, compiled to `frontend/style.css`. The `_legacy.scss` partial contains the original CSS (do not edit it).
- **Backend**: Python 3 + Flask. Serves `frontend/` as static files.
- **Scheduling solver**: Google OR-Tools (min-conflicts) in `backend/scheduler.py`.
- **Data**: pandas + openpyxl for Excel files.

## Architecture

```
start.py                         → entry point: scan images + generate JSON → start Flask
backend/back.py                  → Flask: static routes + /api/upload, /api/replan, /api/download
backend/scheduler.py             → OptimizedRepetitionScheduler (multi-rehearsal + forced assignments)
backend/scan_images.py           → scans images/public/ → frontend/data/gallery-structure.json
backend/generate_team_gallery.py → reads team-profiles.json → merges into gallery-structure.json
team-profiles.json               → single source of truth for team members
frontend/data/site-config.json  → single source of truth for events, videos, about text (edit annually)
frontend/data/gallery-structure.json → generated by start.py — do not edit manually
frontend/src/js/                 → one ES module per page (home.js, about.js, gallery.js, videos.js, planner.js, contact.js, nav.js, utils.js)
frontend/src/scss/               → SCSS partials — one per page
frontend/js/                     → jQuery + legacy plugins (do not modify)
```

## Key Design Decisions

- **ES modules** are deferred by default, so they always run after the classic jQuery scripts. This is intentional — modules access `window.$` for OwlCarousel/FlexSlider re-initialization.
- **gallery-structure.json** is now served from `/data/gallery-structure.json` (not `/gallery-structure.json`). The Flask `/data/<path>` route serves `frontend/data/`.
- **Rehearsal count**: the `Répétitions` column in the repartition Excel expands pieces internally as `"Piece#1"`, `"Piece#2"`, etc. The solver treats them as independent instances but groups them back in `get_json_data()`.
- **Forced assignments** in the planner: pieces pinned by drag-and-drop have conflict cost = 0 if in the forced slot, 10^9 otherwise — they always win.
- **Run ID system**: `/api/upload` saves uploaded files as `{run_id}_dispo.xlsx` and `{run_id}_repart.xlsx`, returns `run_id` in JSON. `/api/replan` loads them by run_id for re-runs without re-uploading.
